=================================================================
1. PROBLEMAS ENCONTRADOS NO SCRIPT.JS ORIGINAL
=================================================================

O script original enviado possui alguns problemas que impedem a
integração de funcionar corretamente.

PROBLEMA 1 — collection foi importado duas vezes

Código original:

import {
    getFirestore,
    collection,
    addDoc
} from "firebase/firestore";

import {
    collection,
    getDocs
} from "firebase/firestore";

A função collection aparece duas vezes no mesmo módulo.

Correção:
fazer apenas uma importação:

import {
    getFirestore,
    collection,
    getDocs
} from "firebase/firestore";


PROBLEMA 2 — não existe código para capturar o formulário

O código tenta utilizar:

nome
sobrenome
email
usuario
senha
confirmarSenha
formulario

Mas nenhuma dessas variáveis foi criada no JavaScript.

É necessário obter os elementos HTML com document.getElementById()
e capturar o evento submit do formulário.


PROBLEMA 3 — o try/catch está sendo executado imediatamente

O código original possui:

try {
    await addDoc(...)
}

Isso significa que o navegador tenta executar o cadastro assim que
o script é carregado.

O correto é colocar o addDoc/createUserWithEmailAndPassword
dentro de um evento:

formulario.addEventListener("submit", async (event) => {
    ...
});


PROBLEMA 4 — a senha está sendo salva no Firestore

O código original contém:

senha: senha,
confirmarSenha: confirmarSenha,

ISSO NÃO DEVE SER FEITO.

A senha deve ser administrada pelo Firebase Authentication.

O Firestore deve armazenar apenas os dados complementares do usuário.


PROBLEMA 5 — Firestore sozinho não cria login

O código original utiliza apenas:

getFirestore()
addDoc()

Isso grava documentos no banco, mas não cria uma conta de
autenticação.

Para login/cadastro com e-mail e senha é necessário utilizar
Firebase Authentication.


PROBLEMA 6 — não existe código de login

O script original não utiliza:

signInWithEmailAndPassword()

Portanto, ainda não existe autenticação de usuários.


PROBLEMA 7 — a consulta getDocs() não é necessária para o cadastro

O código original consulta toda a coleção "contatos" logo após
o carregamento do script.

Isso não é necessário para realizar cadastro/login e pode gerar
problemas de permissão.

A leitura do Firestore deve acontecer quando realmente houver
necessidade de consultar os dados.

3. ESTRUTURA DO FIRESTORE
=================================================================

A coleção recomendada será:

usuarios

Cada usuário terá como ID do documento o próprio UID fornecido pelo
Firebase Authentication.

Exemplo:

usuarios
   |
   +-- abc123xyz
          |
          +-- nome: "João"
          +-- sobrenome: "Silva"
          +-- email: "joao@email.com"
          +-- usuario: "joao123"
          +-- uid: "abc123xyz"
          +-- criadoEm: timestamp


VANTAGEM:

O UID permite relacionar diretamente o usuário autenticado com
seu documento no Firestore.

4. CONFIGURAÇÃO DO FIREBASE
=================================================================

No Firebase Console:

1. Abra o projeto.
2. Vá em Configurações do projeto.
3. Registre seu aplicativo Web.
4. Copie o objeto firebaseConfig.
5. Ative Authentication.
6. Ative o provedor "E-mail/senha".
7. Ative o provedor "Google", caso queira utilizar o botão
   "Entrar com Google".
8. Crie o Cloud Firestore Database.
9. Configure as regras de segurança.


O objeto será semelhante a:

const firebaseConfig = {
    apiKey: "SUA_API_KEY",
    authDomain: "SEU_PROJETO.firebaseapp.com",
    projectId: "SEU_PROJECT_ID",
    storageBucket: "SEU_STORAGE_BUCKET",
    messagingSenderId: "SEU_MESSAGING_SENDER_ID",
    appId: "SEU_APP_ID"
};


NÃO substitua os valores pelos valores acima.

Use exatamente o objeto fornecido pelo seu projeto Firebase.

7. SCRIPT.JS FINAL
=================================================================

IMPORTANTE:

O código abaixo foi organizado para funcionar tanto na tela de
login quanto na tela de cadastro, mesmo que as duas utilizem
id="formulario".

Também utiliza módulos do Firebase via navegador, apropriados para
um projeto HTML/JavaScript simples.

---------------------------------------------------------------

/*
 * =============================================================
 * 1. IMPORTAÇÃO DO FIREBASE
 * =============================================================
 */

import { initializeApp }
    from "https://www.gstatic.com/firebasejs/12.18.0/firebase-app.js";

import {
    getAuth,
    createUserWithEmailAndPassword,
    signInWithEmailAndPassword,
    GoogleAuthProvider,
    signInWithPopup,
    signOut,
    onAuthStateChanged
} from "https://www.gstatic.com/firebasejs/12.18.0/firebase-auth.js";

import {
    getFirestore,
    doc,
    setDoc,
    serverTimestamp
} from "https://www.gstatic.com/firebasejs/12.18.0/firebase-firestore.js";


/*
 * =============================================================
 * 2. CONFIGURAÇÃO DO PROJETO
 * =============================================================
 *
 * COPIE o objeto firebaseConfig do Firebase Console.
 */

const firebaseConfig = {
    // Cole aqui a configuração do seu projeto.
};


/*
 * =============================================================
 * 3. INICIALIZAÇÃO DO FIREBASE
 * =============================================================
 */

const app = initializeApp(firebaseConfig);


/*
 * =============================================================
 * 4. SERVIÇO DE AUTENTICAÇÃO
 * =============================================================
 */

const auth = getAuth(app);


/*
 * =============================================================
 * 5. SERVIÇO DO FIRESTORE
 * =============================================================
 */

const db = getFirestore(app);


/*
 * =============================================================
 * 6. LOCALIZAR ELEMENTOS DA PÁGINA
 * =============================================================
 *
 * O mesmo script.js é carregado pelas duas páginas.
 *
 * Por isso usamos document.getElementById() e verificamos
 * se o elemento existe antes de utilizar.
 */

const formulario = document.getElementById("formulario");

const mensagem = document.getElementById("mensagem");


/*
 * =============================================================
 * 7. FUNÇÃO PARA MOSTRAR MENSAGENS
 * =============================================================
 */

function mostrarMensagem(texto) {

    if (mensagem) {

        mensagem.textContent = texto;

    }

}


/*
 * =============================================================
 * 8. CADASTRO
 * =============================================================
 *
 * O cadastro só será executado se existirem os campos:
 *
 * nome
 * sobrenome
 * email
 * usuario
 * senha
 * confirmarSenha
 *
 * Isso diferencia a página de cadastro da página de login.
 */

const campoNome = document.getElementById("nome");

const campoSobrenome =
    document.getElementById("sobrenome");

const campoUsuario =
    document.getElementById("usuario");

const campoSenha =
    document.getElementById("senha");

const campoConfirmarSenha =
    document.getElementById("confirmarSenha");


if (
    formulario &&
    campoNome &&
    campoSobrenome &&
    campoUsuario &&
    campoSenha &&
    campoConfirmarSenha
) {

    formulario.addEventListener("submit", async (event) => {

        /*
         * Impede o navegador de recarregar a página.
         */
        event.preventDefault();


        /*
         * Captura os valores digitados.
         */
        const nome = campoNome.value.trim();

        const sobrenome =
            campoSobrenome.value.trim();

        const email =
            document.getElementById("email").value.trim();

        const usuario =
            campoUsuario.value.trim();

        const senha =
            campoSenha.value;

        const confirmarSenha =
            campoConfirmarSenha.value;


        /*
         * =====================================================
         * VALIDAÇÃO DAS SENHAS
         * =====================================================
         */

        if (senha !== confirmarSenha) {

            mostrarMensagem(
                "As senhas não são iguais."
            );

            return;
        }


        try {

            mostrarMensagem(
                "Criando sua conta..."
            );


            /*
             * =================================================
             * CRIAR CONTA NO FIREBASE AUTHENTICATION
             * =================================================
             *
             * A senha é enviada ao Authentication.
             *
             * NÃO salvamos a senha no Firestore.
             */

            const userCredential =
                await createUserWithEmailAndPassword(
                    auth,
                    email,
                    senha
                );


            /*
             * O Firebase criou o usuário.
             *
             * Agora podemos obter o UID.
             */

            const user = userCredential.user;


            /*
             * =================================================
             * SALVAR DADOS COMPLEMENTARES NO FIRESTORE
             * =================================================
             *
             * O documento será criado em:
             *
             * usuarios / UID_DO_USUARIO
             */

            await setDoc(
                doc(db, "usuarios", user.uid),
                {
                    uid: user.uid,
                    nome: nome,
                    sobrenome: sobrenome,
                    email: email,
                    usuario: usuario,
                    criadoEm: serverTimestamp()
                }
            );


            /*
             * Cadastro concluído.
             */

            mostrarMensagem(
                "Cadastro realizado com sucesso!"
            );


            /*
             * Limpa o formulário.
             */

            formulario.reset();


            /*
             * Redireciona para a tela de login.
             *
             * Se seu login estiver em outro arquivo,
             * altere "form.html".
             */

            setTimeout(() => {

                window.location.href = "form.html";

            }, 1500);


        } catch (error) {

            console.error(
                "Erro no cadastro:",
                error
            );


            /*
             * =================================================
             * TRATAMENTO DE ERROS
             * =================================================
             */

            if (
                error.code ===
                "auth/email-already-in-use"
            ) {

                mostrarMensagem(
                    "Este e-mail já está cadastrado."
                );

            }

            else if (
                error.code ===
                "auth/invalid-email"
            ) {

                mostrarMensagem(
                    "O e-mail informado é inválido."
                );

            }

            else if (
                error.code ===
                "auth/weak-password"
            ) {

                mostrarMensagem(
                    "A senha informada é muito fraca."
                );

            }

            else {

                mostrarMensagem(
                    "Erro ao realizar cadastro."
                );

            }

        }

    });

}


/*
 * =============================================================
 * 9. LOGIN COM E-MAIL E SENHA
 * =============================================================
 *
 * Na tela de login, o formulário possui:
 *
 * id="formulario"
 *
 * e os campos:
 *
 * id="email"
 * id="password"
 */

const campoPassword =
    document.getElementById("password");


if (
    formulario &&
    campoPassword &&
    !campoNome
) {

    formulario.addEventListener("submit", async (event) => {

        event.preventDefault();


        const email =
            document.getElementById("email").value.trim();

        const senha =
            campoPassword.value;


        try {

            mostrarMensagem(
                "Entrando..."
            );


            /*
             * Autentica o usuário.
             */

            const userCredential =
                await signInWithEmailAndPassword(
                    auth,
                    email,
                    senha
                );


            const user =
                userCredential.user;


            console.log(
                "Usuário autenticado:",
                user.uid
            );


            mostrarMensagem(
                "Login realizado com sucesso!"
            );


            /*
             * Redirecionamento após login.
             *
             * Altere o nome do arquivo conforme seu projeto.
             */

            setTimeout(() => {

                window.location.href =
                    "principal.html";

            }, 1000);


        } catch (error) {

            console.error(
                "Erro no login:",
                error
            );


            if (
                error.code ===
                "auth/invalid-credential"
            ) {

                mostrarMensagem(
                    "E-mail ou senha incorretos."
                );

            }

            else {

                mostrarMensagem(
                    "Não foi possível realizar o login."
                );

            }

        }

    });

}


/*
 * =============================================================
 * 10. LOGIN COM GOOGLE
 * =============================================================
 *
 * O botão precisa ter:
 *
 * id="googleLogin"
 *
 * e type="button".
 */

const googleLogin =
    document.getElementById("googleLogin");


if (googleLogin) {

    googleLogin.addEventListener(
        "click",
        async () => {

            try {

                const provider =
                    new GoogleAuthProvider();


                /*
                 * Abre a janela de autenticação do Google.
                 */

                const result =
                    await signInWithPopup(
                        auth,
                        provider
                    );


                const user =
                    result.user;


                console.log(
                    "Login Google:",
                    user.uid
                );


                /*
                 * Opcional:
                 * criar/atualizar documento do usuário
                 * no Firestore.
                 */

                await setDoc(
                    doc(db, "usuarios", user.uid),
                    {
                        uid: user.uid,
                        nome: user.displayName || "",
                        email: user.email || "",
                        foto: user.photoURL || "",
                        atualizadoEm: serverTimestamp()
                    },
                    {
                        merge: true
                    }
                );


                window.location.href =
                    "principal.html";


            } catch (error) {

                console.error(
                    "Erro no login com Google:",
                    error
                );


                mostrarMensagem(
                    "Não foi possível entrar com Google."
                );

            }

        }
    );

}


/*
 * =============================================================
 * 11. OBSERVAR O ESTADO DE AUTENTICAÇÃO
 * =============================================================
 *
 * Essa função informa se existe um usuário autenticado.
 */

onAuthStateChanged(auth, (user) => {

    if (user) {

        console.log(
            "Usuário conectado:",
            user.email
        );

    } else {

        console.log(
            "Nenhum usuário conectado."
        );

    }

});


/*
 * =============================================================
 * 12. LOGOUT
 * =============================================================
 *
 * Se existir um botão:
 *
 * <button id="btnLogout">Sair</button>
 *
 * este código encerrará a sessão.
 */

const btnLogout =
    document.getElementById("btnLogout");


if (btnLogout) {

    btnLogout.addEventListener(
        "click",
        async () => {

            try {

                await signOut(auth);

                window.location.href =
                    "form.html";

            } catch (error) {

                console.error(
                    "Erro ao sair:",
                    error
                );

            }

        }
    );

}


=================================================================
8. POR QUE USAMOS setDoc EM VEZ DE addDoc?
=================================================================

O addDoc cria um documento com ID automático.

Exemplo:

usuarios
   |
   +-- X7abc123
   +-- K9xyz456


Isso funciona.

Porém, para usuários autenticados é mais didático e conveniente
utilizar o UID como ID do documento:

usuarios
   |
   +-- UID_DO_USUARIO


Assim podemos criar regras como:

request.auth.uid == userId


Isso permite que um usuário acesse apenas o próprio documento.


=================================================================
9. REGRAS DE SEGURANÇA DO FIRESTORE
=================================================================

Uma regra inicial para a coleção "usuarios" pode ser:

rules_version = '2';

service cloud.firestore {

  match /databases/{database}/documents {

    match /usuarios/{userId} {

      allow read, write:
        if request.auth != null
        && request.auth.uid == userId;

    }

  }

}


EXPLICAÇÃO:

request.auth != null

Significa que o usuário precisa estar autenticado.


request.auth.uid == userId

Significa que o UID do usuário autenticado precisa ser igual
ao ID do documento que ele está tentando acessar.


IMPORTANTE:

Não use em produção:

allow read, write: if true;


Essa configuração permite acesso sem a proteção adequada.

14. IMPORTANTE — NÃO SALVAR SENHA
=================================================================

NUNCA faça:

await setDoc(doc(db, "usuarios", user.uid), {

    senha: senha,

    confirmarSenha: confirmarSenha

});


O Firebase Authentication já é responsável pela senha.

Faça:

await setDoc(doc(db, "usuarios", user.uid), {

    uid: user.uid,
    nome: nome,
    sobrenome: sobrenome,
    email: email,
    usuario: usuario,
    criadoEm: serverTimestamp()

});


=================================================================
15. OBSERVAÇÃO SOBRE O CAMPO "USUARIO"
=================================================================

O campo "usuario" será salvo no Firestore.

Porém, o Firebase Authentication, neste exemplo, fará login
utilizando o e-mail.

Portanto:

Login:
    e-mail + senha

Dados adicionais:
    nome
    sobrenome
    usuario


Se o objetivo da aula for permitir login usando o campo
"usuario" em vez do e-mail, será necessário criar uma lógica
adicional para localizar o e-mail correspondente ao usuário.


=================================================================
16. OBSERVAÇÃO SOBRE O LOGIN GOOGLE
=================================================================

Quando o usuário entra pelo Google, o Firebase fornece dados
como:

displayName
email
photoURL
uid


Por isso o script pode salvar alguns desses dados no Firestore.

A senha do Google também NÃO deve ser armazenada no Firestore.
